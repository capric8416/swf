- 单台高配服务器：16 核 CPU / 32GB 内存 / 1TB SSD
- 所有服务容器化部署
- 所有服务单实例运行

**设计目标调整**：
1. 简单性：最简单部署方案，降低运维复杂度
2. 实用性：满足内部系统使用需求
3. 易维护：容器化部署，所有服务单实例
4. 安全性：网络安全、数据加密、访问控制
5. 可监控：基础监控，及时告警
6. 可扩展：预留扩展能力，后期可根据需要升级

#### 2. Docker Compose 配置（11 个服务）
- Nginx：反向代理
- FastAPI：应用服务（单实例）
- PostgreSQL：数据库（单节点）
- Redis：缓存（单节点）
- Celery Worker：异步任务
- Celery Beat：定时任务
- Prometheus：监控
- Grafana：可视化
- Elasticsearch：日志存储
- Logstash：日志收集
- Kibana：日志可视化

#### 3. 监控方案
- Prometheus + Grafana + ELK Stack
- 应用指标、系统指标、数据库指标
- 告警规则：错误率、响应时间、CPU、内存、磁盘
- 告警通知：邮件、企业微信、短信

#### 4. 备份策略
- PostgreSQL：每日全量 + WAL 归档（保留 30 天）
- Redis：每小时 RDB 快照（保留 7 天）
- 应用配置：Git 仓库 + 备份服务器

#### 5. 高可用方案说明

**当前简化方案**：
- 应用层：单实例部署
- 数据库：单节点 PostgreSQL
- 缓存：单节点 Redis
- 监控：本地部署

**未来扩展路径**：

| 数据库 | PostgreSQL 主从 | 数据量>500GB |
| 缓存 | Redis 哨兵/集群 | 内存使用>80% |
| 监控 | 独立监控服务器 | 监控数据量大 |
