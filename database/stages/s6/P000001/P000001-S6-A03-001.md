## 三、页面架构

### 3.1 整体布局

采用经典的上下结构 + 左侧导航布局：

```
+------------------------------------------+
|              Header (64px)               |
+----------+-------------------------------+
|          |                               |
| Sidebar  |         Main Content          |
| (256px)  |                               |
|          |                               |
+----------+-------------------------------+
|              Footer (optional)           |
+------------------------------------------+
```

#### Header 区域

**高度**：64px

**包含元素**：
- Logo（左侧）
- 全局搜索框（可选）
- 通知图标
- 用户头像下拉菜单

#### Sidebar 区域

**宽度**：256px

**包含内容**：
- 主导航菜单
- 项目快速切换（可选）

**交互**：
- 支持收起/展开
- 当前页面高亮
- 支持子菜单展开

#### Main Content 区域

**布局**：自适应宽度

**内边距**：24px

**最大宽度**：1440px（居中）

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端

    U->>F: 点击登录按钮
    F->>F: 表单验证

    F->>F: 存储 Token
    F->>F: 跳转到首页
    F-->>U: 显示登录成功提示
```
