## 五、技术栈确认

### 前端技术栈
- **框架**: Vue 3 + TypeScript
- **UI 库**: Element Plus
- **图表库**: Apache ECharts
- **状态管理**: Pinia (推荐)

### 后端技术栈
- **框架**: FastAPI
- **ORM**: SQLAlchemy
- **数据验证**: Pydantic
- **认证**: JWT

### 数据层
- **数据库**: PostgreSQL 15
- **缓存**: Redis 7
- **任务队列**: Celery + Redis
- **定时调度**: pg_cron (待最终确认)

### 部署运维
- **容器化**: Docker Compose
- **监控**: Prometheus + Grafana + ELK
- **部署**: 单服务器 (16 核/32GB/1TB SSD)
