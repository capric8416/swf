**模块 ID**：MOD-001  
**模块名称**：全局统计  
**模块描述**：提供研发中心整体 Coding Agent 使用情况的宏观统计视图，支持管理层决策

| F-001-03 | 高频使用人员TOP 20 | IR006 | P0 | 12h |

#### 核心用户故事

**用户故事 1：全局Token使用趋势看板**

```
作为：研发中心管理层
我希望：查看全中心 Coding Agent Token 使用趋势
以便：了解 AI 工具的整体使用情况和成本投入

验收标准：
1. 展示近 30 天每日 Token 使用量趋势（折线图）
2. 展示累计 Token 使用总量
3. 展示日均 Token 使用量
4. 支持按周/月维度切换
5. 数据每日凌晨 2 点自动更新
```

**用户故事 2：全中心Coding Agent使用活跃度趋势**

```
作为：研发中心管理层
我希望：查看全中心 Coding Agent 使用活跃度趋势
以便：评估 AI 工具在研发团队的普及程度

验收标准：
1. 展示近 30 天每日活跃用户数趋势（折线图）
2. 展示当前活跃用户数/总用户数
3. 展示人均每日使用时长
4. 支持按平台维度筛选（Trae/Cursor/Copilot）
5. 数据每日凌晨 2 点自动更新
```

**用户故事 3：高频使用人员TOP 20**

```
作为：研发中心管理层
我希望：查看 Coding Agent 使用频率最高的 20 人
以便：识别 AI 工具的积极使用者和潜在推广者

验收标准：
1. 展示近 7 天 Token 使用量 TOP 20 人员列表
2. 展示每人累计使用时长、采纳率
3. 支持导出 Excel 格式
4. 支持按项目维度筛选
5. 数据实时计算（基于已同步数据）
```
